# Tally Market

A responsive e-commerce storefront built with plain HTML, CSS Grid, and JavaScript.

## Run on Windows

1. Install Python 3 if it is not already installed.
2. Double-click `start.bat`.
3. Keep the command window open while using the site.

The site opens at `http://127.0.0.1:8000`. Do not open `index.html` directly as
a file because browsers may block the product API request. An internet
connection is required for FakeStoreAPI products and images.

The first screen is a demo sign-in. Enter any valid email and a password of at
least six characters to continue; no real account is checked, and the password
is never saved.

Checkout is simulated. The demo does not collect payment details or process a
real order.
