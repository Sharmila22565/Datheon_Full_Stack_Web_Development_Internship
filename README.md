# Datheon Full Stack Web Development Internship

This repository contains three web development projects completed as part of the **Datheon Full Stack Web Development Internship**. These projects helped me improve my practical knowledge of web development, responsive design, JavaScript, and user interface development.

## Projects

### 1. Daymark – Task Manager

A personal task management application with a clean, focused dashboard.

- Add, edit, delete, search, filter, and complete tasks.
- Add categories and due dates.
- View task progress and completion statistics.
- Demonstration sign-in and task storage in the browser.
- Responsive layout for desktop and mobile devices.

**Technologies:** HTML5, CSS3, JavaScript, Local Storage, Session Storage

**Folder:** [crud](./crud)

### 2. Tally Market – E-Commerce Storefront

A responsive e-commerce storefront that displays products and provides an interactive shopping experience.

- Sign-in demonstration.
- Product browsing and category filters.
- Product search and sorting.
- Shopping cart with quantity controls.
- Cart persistence using browser storage.
- Simulated checkout flow.
- Products and images loaded from Fake Store API.

**Technologies:** HTML5, CSS3, JavaScript, Fake Store API, Local Storage

**Folder:** [ecom](./ecom)

### 3. Personal Portfolio

A modern personal portfolio website that presents my profile, skills, experience, projects, achievements, certifications, and contact information.

- Responsive sections and smooth animations.
- Light and dark theme support.
- Interactive project gallery and project details.
- Resume download.
- Contact and social media links.

**Technologies:** React, Vite, JavaScript, HTML5, CSS3, Tailwind CSS, Framer Motion, Lucide React

**Folder:** [sharmiportfolio](./sharmiportfolio)

## Getting Started

### Run Daymark

Open the `crud` folder and launch `index.html` in a browser, or run a local server:

```bash
cd crud
python -m http.server 8000
```

Visit `http://127.0.0.1:8000` in your browser.

### Run Tally Market

Open the `ecom` folder and run `start.bat`.

The application will be available at `http://127.0.0.1:8000`.

Python 3 is required for the local server.

### Run the Portfolio

```bash
cd sharmiportfolio
npm install
npm run dev
```

Open the local URL shown by Vite in the terminal.
